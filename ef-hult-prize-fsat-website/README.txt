RUN LOCALLY

DEPLOY TO VERCEL
1. Upload the full project folder to GitHub.
2. Import the repository into Vercel.
3. Choose Framework Preset: Other.
4. Set the root directory to the folder containing index.html.
5. Deploy.

External images and Google Fonts need an internet connection.
